# Финансы 3D — iOS launcher

Ссылка на веб-приложение уже записана в index.html. Откройте опубликованный HTTPS-адрес в Safari и добавьте на экран «Домой». Для ручной смены адреса на одном устройстве откройте страницу лаунчера с ?setup=1.

Режим открытия: прямой автоматический переход. Публикуйте содержимое архива в корне статического сайта. В режиме iframe целевое приложение должно разрешать встраивание.
